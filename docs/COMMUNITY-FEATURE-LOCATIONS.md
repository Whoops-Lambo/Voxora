# Where to find the community update

The public site and a desktop connected to Public Voxora use the same hosted interface. Both need the matching public deployment. **User Settings → Server Connection** shows the service version and, on desktop, the installed app version.

| Feature | Open this control |
| --- | --- |
| Grant Voxora Max | Platform Admin → Voxora Max → search member → Grant Max |
| Grant boost level 4 or 5 | Platform Admin → Server Boosts → select server → Grant/Change Boost Grant |
| Recovery | Server menu → Server Management → Recovery |
| Role templates, permissions, temporary roles and icons | Server Settings → Roles / Members |
| Restricted emoji roles | Server Settings → Emoji → Restrict to Roles |
| Stage, Forum, Rules & Onboarding, Media / Showcase | Create Channel; then Channel Settings for its detailed controls |
| Rules screening and optional roles | Server Settings → Onboarding; members open Server Guide |
| Create a thread | Message menu → Create Thread |
| Move/merge a thread or forum discussion | Open its discussion → Move / Merge Discussion |
| Real-money server shop | Server menu → Server Store; staff publish products in Server Settings → Server Store |
| Seller payouts | Server Settings → Server Store → Set Up Seller Payouts |
| Group chats | Chats → Group Chats; invitations require consent |
| Bot templates | Server Settings → Bots & Apps |
| Owned bot and command limits | Developer Portal; current plan quotas are displayed above applications |
| Custom/shared app themes and Max Workspace Scenes | User Settings → Custom Themes |
| Webhooks and public live-chat widgets | Server Settings → Webhooks & Widgets |
| Reaction roles and level rewards | Server Settings → Reaction Roles & Leveling |
| Leaderboard | Server menu → Level Leaderboard |
| Account switcher | User Settings → My Account → Add Account / Switch |
| Personal channel order/visibility | Server menu → Customize Channel List |
| DM folders | Chats → Organize DMs |
| Game detection, Playing status and game-chat shortcut | User Settings → My Account; desktop shortcut defaults to Ctrl+Shift+O |
| Advanced search | Channel toolbar → Search Messages; `OR`, `NOT`, `-term`, `mentions:`, `is:` and `has:` filters |
| Follow announcements | Source Announcement Channel → Follow → select destination server/channel |
| Publish announcements | Source announcement's message menu → Publish Announcement |
| Embeds and message buttons | Bot SDK channel-message payloads; see RICH-MESSAGES.md |
| Join/leave sounds | User Settings → Voice & Video → Voice Join and Leave Sounds |
| Per-user stream audio and pop-outs | Voice participant card → Stream Audio / Pop-out Audio Controls |
| Audit/leave logs and export | Server Settings → Audit Log |
| View Server as Role | Server Settings → Roles → select role → View Server as Role |

Free/Plus/Max bot limits are **20 / 100 / 250 applications**, with **200 / 400 / 1,000 commands per bot**. Groups allow **20 / 40 / 80 members**. Plus creates **2** themes and Max creates **10**. Max adds six boost slots, twenty Workspace Scenes and ninety-day recovery for owned servers. Owner grants do not require charging a subscription.

Role icons require boost level 2; animated icons require level 3. Store highlights and longer server recovery are added at levels 4 and 5. See [the detailed feature and boost tables](COMMUNITY-4.md) for quotas, permissions, retention and transport limits.

A real-money store needs platform Stripe Connect configuration and seller verification before it can charge a buyer. Web widgets require an administrator to confirm publishing a public channel. Staff-only controls appear only to authorized accounts. Mobile browsers expose the same server/webhook controls through the responsive settings menu. Native game detection and the game window require the Windows desktop app.
