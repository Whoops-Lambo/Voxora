Voxora 2.10 adds a complete server moderation workflow.

- AutoMod rules for words and phrases, blocked link domains, mention limits, message floods and repeated messages, with Block or Flag actions, exemptions and previews.
- Member reports for server messages and thread replies, private receipts and live resolution status.
- A private moderation queue with claims, notes, evidence snapshots, search, filters, pagination and conflict protection.
- Permission-checked source deletion, timeouts, kicks and bans from a case; normal channel privacy and role hierarchy remain enforced.
- A seven-day channel activity dashboard with message, author, report and AutoMod counts.

Configure rules in Server Settings → AutoMod and review cases from the server dropdown → Moderation Queue. Delegate Manage AutoMod and Review Reports through Roles; enforcement actions still require their own permissions. AutoMod starts disabled on existing servers.

Desktop 2.8+ clients can receive this release through the automatic updater. Shared backends require their own 2.10 upgrade. This unsigned Windows installer was cross-built and archive-verified in Linux; native Windows installation/update/relaunch remains untested.
