Voxora 2.11 adds personal server organization and settings portability.

- Private server folders with colors, drag-and-drop, move controls, local collapse state, unread/mention badges and Mark Folder as Read.
- Folder membership and server order synchronize across your account's devices; deleting a folder keeps its servers.
- Account-synced theme, compact display, font size and reduced-motion preference, with migration of existing local appearance.
- Settings export, import preview, Merge/Replace modes and conflict protection. Imports never join or leave servers, and skip unavailable IDs.
- Safe queuing of rapid appearance edits while preserving conflicts with another device's changes.
- Readable light-theme user settings and reduced-motion controls that also respect the operating system preference.

Find these features in User Settings → Server Organization, Appearance and Settings Backup, or right-click a server icon. Microphone choices, volume, notification permissions, messages and tokens stay out of settings exports.

Desktop 2.8+ copies receive the release through the existing updater. To request an immediate check, the first-account platform owner can use Platform Admin → Updates → Notify Desktop Clients; each user then chooses Restart and Install. Upgrade shared backends separately for the new web UI and APIs. This unsigned installer was cross-built on Linux; native Windows installation/update/relaunch remains untested.
