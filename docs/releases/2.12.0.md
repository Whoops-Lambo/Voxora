Voxora 2.12 introduces Voxora Plus at US$9.99/month or US$89.99/year.

- 25 MB uploads, 4,000-character messages/thread replies, and 500-character bios.
- Gradient profile banners, profile accents and an optional Plus badge.
- Two server boost slots; two active boosts unlock 100 custom emoji slots.
- A public Plus plan page, member subscription controls, and owner-only complimentary grants/revocation with audit history.
- Stripe hosted subscriptions, billing portal, signed webhooks, exact-price validation, duplicate-checkout prevention and delayed-confirmation recovery.
- Expiry/revocation checks preserve normal channel permissions and existing content. Test and live billing bindings stay separate.

Open User Settings → Voxora Plus or visit /plus. The first-account platform owner can grant access in Platform Admin → Plus. Real purchases remain disabled until the hosted backend's Stripe keys, recurring price IDs, signing secret, public HTTPS URL and billing portal are configured. See docs/PLUS.md; the installer contains no payment credentials.

Desktop 2.8+ clients receive this release through the updater. Shared backends need their own upgrade. The unsigned Windows installer is cross-built and archive-verified on Linux; native Windows installation/update/relaunch remains untested. Stripe flows are tested with a local mock, not live charges.
