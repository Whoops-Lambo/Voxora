Voxora 2.15.0 introduces a midnight navy and mint design and a private Home hub.

- A branded navigation bar and horizontal community ribbon replace the vertical server rail. Named community tabs, folder labels, rounded conversation panels and matching setup/website styling give Voxora its own visual identity. Narrow screens keep a scrollable community ribbon and collapsible channel sidebar.
- Home brings together community cards, unread totals, starred channel and DM shortcuts, and upcoming/due reminders. Starred shortcuts sync across your sessions and hide when access is revoked or a conversation is blocked.
- Private reminders support custom notes, message and threaded-reply references, local date/time selection, quick time presets, completion, restore, edit, deletion and fifteen-minute snooze. Due items persist until resolved. Revision checks prevent stale edits. Generic due alerts respect sound/desktop preferences and Do Not Disturb.
- Reminder previews recheck current source access. Deleted, blocked or inaccessible sources show as unavailable without retaining copied source text. Reminder titles and private notes belong only to their account, including when another account has platform staff permissions.
- Mint, Copper and Iris accents work with dark/light themes and sync with account appearance, including portable appearance exports.
- Automatic updates retain the 2.14 fixes: startup/minute checks, wake/reconnect checks, retry backoff, verified Git LFS fallback downloads and an independent Windows helper. The Windows validation also exercises the unmodified updater extracted from the published 2.14 installer against this production installer, including scheduled discovery, background download, real installation and relaunch.

Installed Windows clients on 2.14 with automatic downloads enabled discover this release from the published feed and download it in the background. Choose Restart and Install when ready. If an older updater cannot finish, install 2.15 manually once. No domain is required. Desktop updates preserve local data and saved connections; separately hosted backends need their own source update to expose new features.

Validation passed: all 47 browser scenarios and 79 applicable backend/helper tests. Four Windows-only local skips are covered by native Windows validation. The [Windows production run](https://github.com/Whoops-Lambo/Voxora/actions/runs/41364535659) passed compiled installer regressions, domain-free setup, local/shared connections, exclusive first-account ownership, reinstall/uninstall and data preservation. It also passed automatic discovery/download and real installer/relaunch cycles using both candidate code and the unmodified updater/PowerShell scripts extracted from the SHA-256-verified published 2.14 installer. Native network responses are fixtures containing the production installer; executable processes are real.
