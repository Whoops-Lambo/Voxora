Voxora 2.16.0 adds scheduled messages, a private outbox and a Home view for device drafts.

- Use the composer clock or Home's Send it later section to schedule plain text or replies in text/announcement channels and DMs. Pick a local date/time or use quick presets. Edit, send now, cancel, filter history and jump to sent messages from Outbox.
- Queued text is private to its author and syncs across that account's sessions. Access revocation hides destination names. Delivery rechecks membership, permissions, rules acceptance, account status, blocks, slowmode, AutoMod, reply targets, emoji and current Plus limits. Failed items wait for explicit review/rescheduling.
- Messages and delivery receipts share an atomic state write. Queues survive backend restarts and process overdue messages when the backend returns. Shared backends can send while a client is closed; Local Workspaces must be running. Scheduling supports text; attachments, polls, slash commands, forums and threaded replies remain separate flows.
- Home's Drafts on this device view resumes, schedules or clears unsent text. Drafts survive reloads and are separated by account. Signing out clears the visible composer. Device drafts and queued text are excluded from portable appearance exports.
- The corrected 2.15.1 updater confirmation flow is retained. Windows validation upgrades from the immutable published 2.15.1 installer, including automatic discovery/download, focus checks during confirmation, real installation, relaunch and data preservation.

Installed Windows apps on 2.15.1 with automatic downloads enabled receive this through the official update feed. Choose Restart and Install when ready. If an older copy still shows the confirmation error, install the new installer manually once. No domain is required. Separately hosted backends need their own 2.16 source update for scheduling.
