Voxora 2.17.0 brings role and channel configuration into consistent settings windows.

- Server Settings prominently includes Roles and an Overview shortcut. Role creation, names/colors, permissions, display grouping and hierarchy stay inside Server Settings rather than switching to a standalone creation dialog. Member role assignments remain available from Members and their existing shortcuts.
- Channel Settings combines Overview and Permissions, with Forum tags and announcement Following tabs where applicable. Name/topic/category, slowmode, announcement options, role/member overrides, category inheritance and syncing are configured in one window. Saves keep the settings context open.
- Channel Permissions menu actions now lead through Channel Settings. Permission shortcuts from the channel manager open its Permissions tab. Category and forum configuration use the same settings layout, with a route back to Server Settings.
- Management tabs reflect current privileges. Role-only managers can configure channel overrides without gaining channel-detail or deletion controls. Role hierarchy, grant limits and backend authorization remain enforced. Privilege/membership loss closes or redirects settings, and sign-out/suspension clears visible privileged forms.
- Mobile Channel Settings uses a compact tab navigation above its editor. The navy/mint design and existing appearance accents are preserved.

Installed Windows apps check the official feed and download newer releases when automatic downloads are enabled. Choose Restart and Install when ready. The corrected update confirmation flow is retained. Separately hosted backends need the 2.17 source update for these interface changes. No domain is required, and accounts, messages and existing role/channel configuration are preserved.

Validation passed: all 53 browser scenarios, 89 applicable backend/helper checks and all 33 selected Windows updater/installer regressions. The [native Windows production run](https://github.com/Whoops-Lambo/Voxora/actions/runs/41384141741) passed domain-free local/shared startup, automatic download and confirmation handling, real installation/relaunch, reinstall/uninstall and data preservation. Its compatibility cycle upgrades the immutable published 2.16.0 installer using that release’s unmodified updater and helper scripts. Network responses in the native cycles are fixtures containing the production installer; executable processes are real.
