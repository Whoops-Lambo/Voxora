Voxora 2.17.1 — safer Windows updates and repair

The installer now checks free space and extracts the full update before replacing application files. Existing files are backed up with same-drive renames and restored if replacement fails. Unrelated user files, chat data, accounts and saved connections are preserved.

Installation failures identify the affected file and operation in %APPDATA%\Voxora\updates\installer-details.log. The updated helper includes these details, verifies all installed payload hashes, and checks the executable before reopening Voxora.

Publishing now requires Windows to install and relaunch the exact candidate download before the stable update feed changes. The test also exercises an upgrade using the previous shipped updater.

If a failed older update left Voxora unable to open, close it and run the 2.17.1 installer over the same installation folder once. Do not remove your workspace data. If Windows still blocks a file, the new installer log provides the specific failure for diagnosis.
