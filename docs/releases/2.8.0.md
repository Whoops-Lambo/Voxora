Voxora 2.8 adds automatic Windows desktop updates.

- Background checks and downloads, release notes, progress, and a Restart and Install choice.
- Update preferences and verified downloads survive restarts. Corrupted or incomplete downloads are rejected.
- Platform owners can notify connected desktop clients to check for a new release.
- A release pusher publishes the installer, source ZIP, checksums, and an update feed pinned to the exact installer commit.

Accounts, messages, server connections, roles, and bot configuration are preserved. Shared backends and separately running bots still need their own upgrades. Install 2.8 manually once if you are upgrading from 2.7 or earlier.
