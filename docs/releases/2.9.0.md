Voxora 2.9 helps new members find their place in a server.

- Welcome guides with introductions, server rules, and recommended channels.
- Optional rules acceptance for new joins, enforced across posting, reactions, files, threads, and calls.
- Self-selected interest, color, and channel-access roles without increasing moderation rank.
- Live privacy checks, safe withdrawal when offered roles gain staff permissions, and persistent member choices.
- Discovery onboarding works even when every channel is hidden initially.

Configure these features in Server Settings → Onboarding. Existing servers start with onboarding disabled. Shared backends need their own 2.9 upgrade; desktop 2.8+ clients can receive this release through the automatic updater.
