Voxora 3.1 — Make it your community

PROFILE PICTURES
Free user avatars with an inline crop editor, zoom and position controls. Pictures appear across chat, direct messages, member lists and profile cards. Profiles now include pronouns, three labeled website links and a live preview. Uploading an avatar preserves your unsaved profile text.

SERVER BRANDING
Add a server icon and banner from Server Settings → Overview. Branding appears across community navigation, Home and Discovery. Choose a separate invite banner for the public invite page. PNG, JPEG, WebP and GIF source images become cropped static PNGs; remove a picture to restore the default.

LEVEL 3 CUSTOM INVITES
Choose a unique invite name when your server reaches boost level 3. Links use your current Voxora backend, with no fixed domain requirement. Levels unlock at 2, 7 and 14 active boosts, providing 100, 150 and 250 emoji slots. A custom link pauses below level 3 and keeps its name reserved until you remove it. Regular invites remain available independently.

TIMED AND UNLIMITED BOOST GRANTS
Platform Admin → Server Boosts lets the owner grant a minimum level for a number of minutes, hours or days, or unlimited time. Change or revoke grants with an audit reason. Delegate the Manage Server Boosts staff permission without granting other admin tools. Member boost counts remain accurate, and expired grants return to the earned level.

INVITE PREVIEWS
Valid invite pages show community branding before sign-in. Separate invite banners work on both regular and custom invites. The preview excludes messages, channels and member identities; expired or revoked codes stop providing public image access. Members still choose Join Server, and bans remain enforced.

UPGRADES
Existing accounts, chats, roles, bot configuration and saved connections are preserved. External-drive download storage, installation free-space checks, staging and rollback remain in place. Windows installations discover the official feed automatically and offer Restart and Install. Update and restart separately hosted backends with npm ci for these features. No domain is required for Local Workspace.
