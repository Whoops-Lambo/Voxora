Voxora 3.3.0 — Communities and mobile

COMMUNITY SETTINGS
Server settings now include sticker and soundboard management, a Banned Users tab, an onboarding shortcut, and server tags. Emoji, stickers and soundboard clips each have their own capacity: 30 at no boost level, 60 at level 1, 90 at level 2 and 200 at level 3. Existing assets remain stored after a downgrade; assets over the active limit cannot be newly used. Previously sent sticker images remain in message history after the original sticker is deleted.

Boost level 2 unlocks a 2–5 character server tag. Members can opt in through User Settings → Profiles. Level 3 unlocks two independently configurable custom invite links, both using the server’s invite banner. Boosting members automatically receive a Server Booster role; it grants no moderation rank or permissions.

ROLES AND CHANNELS
View Server as Role offers a read-only preview of saved role permissions, visible channels and recent messages. Role display groups and public role mentions remain configurable. New channel and role permissions control stickers, custom emoji, polls, commands, links, screen sharing, soundboard playback, voice activity, Stage moderation and voice member actions. Existing installations retain their previous communication access through a one-time permission migration.

Create Stage channels for speakers and an audience, Media channels for image/video/audio/sticker posts, and Rules channels for controlled publishing. Existing text, voice, forum, announcement and category options remain available. Voice channels can set a participant limit; bypassing it requires its own permission.

VOICE AND CAMERA
Noise suppression, echo cancellation and automatic gain control default on and can be changed under Voice & Video. Push to talk uses V outside text fields; channel roles can require it. Turning off the camera removes the remote video tile, and turning it on again reuses the video connection. Stage audience members can request to speak; moderators approve speakers and move them back to the audience. Voice moderators can server-mute, server-deafen, move or disconnect lower-ranked members using the participant context menu. Camera and screen sharing have separate permissions.

MEMBER MANAGEMENT AND REPORTS
Manage Member now opens a usable menu inside the profile dialog. Platform Admin includes a Reports queue, open-report counts, status/search filters, claiming and audited review actions. Staff roles can receive Review Platform Reports. Reports explicitly shared with Voxora staff include only the reported evidence; private server history and internal moderator notes stay private. Server reviewers retain access to reports in channels they can view.

ANDROID AND IPHONE
An Android release APK and an unsigned iOS IPA are available under mobile-releases. Both connect to the shared public service. Android 7+ is supported. Native iPhone installation requires signing the IPA with your own Apple ID using AltStore Classic or Sideloadly; iOS 16.4+ is required and free provisioning generally needs renewal every seven days. Safari → Share → Add to Home Screen installs the web version without App Store submission or weekly signing. See docs/MOBILE.md for installation and update details.

LIVE CHAT RECOVERY
Messages, member presence and friend requests continue to sync when a proxy blocks the live stream. Voxora reconciles missed messages, edits and deletions after reconnecting while preserving unsent drafts and older-message views. A connection indicator shows Live, Syncing, Connecting or Offline, with retry and server details in User Settings → Server Connection. Background syncing stays active when the Windows app is minimized.

DM AND MENTION SOUNDS
Message sounds default on unless you previously disabled them. Incoming DMs, personal mentions, @here, @everyone and role mentions use short audible pings. Sounds respect channel/server notification rules, mutes, blocked users, Do Not Disturb and the conversation you are actively reading. The first DM in a new conversation is included. Reconnecting and HTTP catch-up do not replay alerts already delivered; old messages at sign-in stay silent. Change Message sounds or use Play Test Sound in User Settings → Notifications.

ONE SHARED PLATFORM
Older saved local-workspace connections show the public connection choices once so people do not unknowingly remain on separate PCs. Join Public Voxora connects to https://voxora-public.onrender.com. Choosing Open Local Workspace explicitly remembers that local-only choice. Local accounts and messages are preserved and remain separate from public accounts. Saved shared connections and installation identity checks remain intact.

HOSTED BACKEND
Deploy this source to the shared Render service to enable chat recovery and new sounds for connected desktop and browser users. New Render Blueprints enable deployments from main. Existing services must enable Auto-Deploy → On Commit or use Manual Deploy → Deploy latest commit; pushing an installer alone does not replace the hosted chat interface. Keep one instance, the persistent disk and the existing owner/data settings. /api/info reports realtimeSync: true after the backend fix is deployed.

The Windows update keeps checksum verification, external-drive download storage, installation-space checks, staged replacement, rollback and user-approved restart.
