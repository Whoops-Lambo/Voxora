Voxora 3.3.1 — Expression and platform safety

EMOJI AS YOU TYPE
Type :name: in chat or thread replies to find custom server emoji and 1,870 standard emoji entries with shortcode aliases. Choose with the mouse, arrows, Enter or Tab. Exact completed shortcodes expand automatically; code examples and URL separators stay intact. The emoji picker searches the full catalog.

PLUS ACROSS SERVERS
Custom emoji, stickers and soundboard clips from another server require active Voxora Plus. Source membership, boost capacity and channel permissions still apply. Standard emoji and same-server custom emoji remain free. Server and channel settings include Use External Emoji, Use External Stickers and Use External Soundboard. Recipients can see shared images and hear voice-channel clips without joining the source server or buying Plus.

PUBLIC WEBSITE AND SAFETY
The homepage links to Terms of Service, Privacy Policy and an anonymous Safety Center. Reports need no login and return a private receipt for status checks. Platform staff review anonymous reports through the existing Reports queue, without a reporter account or receipt key. Report content can contain identifying information; hosting providers can retain connection logs.

SERVER VERIFICATION AND MEMBER MANAGEMENT
Authorized platform staff can grant or revoke server verification, with review reasons and audit entries. Badges appear in server headings, Discovery and invite previews. Name or ownership changes require another review. Manage Member now opens a dedicated foreground panel instead of a menu behind the profile.

IPHONE BACKGROUND ALERTS
On iOS 16.4+, install Voxora through Safari → Add to Home Screen, open that icon and enable Background Notifications in User Settings → Notifications. Web Push supports closed-web-app DM and mention alerts, honoring mutes, blocks, DND, read markers and current channel access. Message previews default off. A native IPA signed with a free Apple ID cannot receive APNs background notifications; the app explains the Home Screen alternative. Physical iPhone/provider delivery still needs device verification.

DEPLOYMENT
Deploy this backend update on Render and reload web/mobile clients. Existing native mobile shells load the hosted interface; their 3.3.0 APK/IPA remain compatible. The Windows update does not deploy the shared backend.
