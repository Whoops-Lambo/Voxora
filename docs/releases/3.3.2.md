Voxora 3.3.2 — Desktop and message notifications

DESKTOP ALERTS
Voxora now supports native desktop notifications for DMs, mentions and eligible server messages. Windows installs register the Voxora application identity on the Start Menu and desktop shortcuts. Clicking a notification restores the app and opens the message or thread. User Settings → Notifications includes Send Test Desktop Notification and Open System Notification Settings.

MESSAGE BANNERS
Clickable in-app banners announce messages while you are in another conversation or Home. Previews default off, and banners can be dismissed. Select All Messages for a server to receive ordinary messages; DMs and eligible mentions follow their conversation settings. Mute, blocks, Do Not Disturb, active viewing and read/catch-up behavior still apply. Sign-out and relevant access changes clear existing alerts.

OPTIONAL BACKGROUND MODE
Enable Keep Voxora running when the window is closed to keep receiving messages from the system tray. Tray mode is off by default. Click the icon to reopen Voxora, or choose Quit Voxora from its tray menu to stop it. A completely quit Windows app cannot receive message alerts. The native Voxora → Notifications menu offers test, system settings and tray controls even with an older hosted interface.

SETUP
Enable Desktop notifications in User Settings → Notifications. Check Windows notification and Focus settings if a test does not appear. Deploy the latest Render backend for the enhanced settings and message banners, then reload the app. Existing native mobile shells remain compatible and use the hosted interface.
