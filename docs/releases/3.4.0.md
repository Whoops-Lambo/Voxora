Voxora 3.4.0 — Mobile, Voice and Sharing

PHONE AND TABLET WORKSPACE
Device-scale chat prevents application pinch/double-tap and input focus zoom. Visible-viewport sizing keeps the composer above the keyboard. Touch controls, safe areas, compact channel menus, message action buttons, settings tabs, dismissible channel navigation and tablet portrait/landscape layouts make the app easier to use without horizontal page scrolling. New native mobile builds explicitly disable webview zoom; iPhone viewport bounce is also disabled.

VOICE MESSAGES
Record microphone messages from the composer, pause/resume, preview, add a caption and send. Recordings stay local until sent. The microphone stops on close or backgrounding. Clips can be up to two minutes in the recording UI and 8 MB, with authenticated audio playback, seeking, speed controls and downloads. Voice & Video microphone processing preferences apply. A new Send Voice Messages permission works with role and channel overrides; Attach Files is also required.

MESSAGE FORWARDING
Forward chat messages and threaded replies to an accessible conversation, with explicit sharing confirmation. Text and attachments become an independent copy with original-author attribution. Forwarding applies source access, destination moderation, upload limits, and Plus requirements for external assets. It does not repeat mentions. Copies cannot be edited to misrepresent the original author.

ADVANCED SEARCH
Search chat and threads by text/phrase, author, channel, attachment kind and UTC date boundaries. Use the Advanced Search form or filters including from:, in:, has:voice, has:image, has:file, has:video, has:link, has:poll, before: and after:. Private-channel and block rules remain enforced.

MOBILE DOWNLOADS
New Android 3.4.0 APK and iPhone 3.4.0 unsigned IPA. Android uses the existing Voxora signing identity. iPhone installation still requires user signing; free Apple IDs do not gain native APNs push. Home Screen Web Push remains available on supported iPhones.

DEPLOYMENT
Deploy the latest backend on Render, then reopen clients for the new hosted interface and APIs. Desktop installation alone cannot deploy the public service. Windows automatic updates preserve the saved connection and existing chat data.
