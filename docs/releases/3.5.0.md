FIND YOUR TOOLS
Open Your Tools from the top bar, Chats sidebar or User Settings. Message menus offer Add to Collection and Read Aloud. More message options offers formatting, preview, quick replies, timestamps and cloud drafts. Profile Time & Status is available from Profiles. Thread replies can be collected or read aloud too.

ACCESS AND PRIVACY
Private tools stay with their account. Collections and conversation libraries hide inaccessible or blocked originals. Server resources can follow a selected channel's visibility. Plus-only writes are enforced by the server; expiration restores default themes/sounds while retaining owned drafts and saved data. Session revocation disconnects that device and removes its background-push subscription. Focus pauses alerts without changing online status.
