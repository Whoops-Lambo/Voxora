Voxora 3.6.0 — Together

PRIVATE GROUP CHATS
Create named groups with topics, colors and accepted invitations. Group owners manage participants, cancel invitations and transfer ownership. Free owners support 10 members; Plus owners support 20. Joining requires confirmation of shared history. Leaving/removal revokes conversation and attachment access. Group messages use the existing files, voice messages, polls, reactions, mentions, read state, search and notifications. One-to-one DMs stay separate.

PROJECT PLANNER
Shared task checklists, prerequisite dependencies with cycle prevention, blocked-work indicators, channel-scoped milestones and progress, task watching, a private Team Updates inbox, task activity history, due-date calendar filters and ICS export. Existing task creators, assignees and Manage Projects permissions determine who can change each part. Stale updates are rejected, and private dependency titles/watcher identities remain protected.

EVENT CENTER
Going/Maybe/Not Going responses; capacity and ordered waitlists; active co-hosts; ordered timed agendas; private RSVP and host notes; confirmed attendee rosters; manual check-in; personal confirmed-event calendar export; event duplication; RSVP/waitlist filters and Home summaries. Places reflect current eligible Going responses and capacity. Private notes are available only to the intended participant and authorized hosts.

FIND TOGETHER
Open Your Tools → Together or Home → Open Together. Servers also expose Project Planner and Event Center in their sidebar and menu. Existing Project Board task details link to their new plan.

NAVIGATION AND LIVE UPDATES
The unread-filter header no longer overlaps Community Studio. Notebook is available from Your Tools on compact phones. Task-status selections stay in place during live refresh, and stale saves continue to require a refresh.

ACTIVATION
Deploy main on Render and reopen clients for the hosted changes. Existing Android/iPhone 3.4 shells remain compatible. Windows updates use the verified release feed and preserve the current connection and workspace data. Plus pricing remains unchanged.
