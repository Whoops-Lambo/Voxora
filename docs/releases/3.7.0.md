SERVER PROFILES

Authorized staff can reset lower-ranked profiles through existing role hierarchy.

SIX NEW PLUS PROFILE OPTIONS
Server-specific accent, gradient banner, headline, labeled links, banner pattern and a clearly member-written community title. Editing includes a preview. Expired Plus falls back to the default appearance while retaining stored styles for renewal. Prices are unchanged.

SUGGESTION BOARD AND ROADMAP
Post channel-scoped ideas, vote once per account, discuss and edit comments, search/filter/sort entries, view roadmap columns, publish official responses, pin, lock and archive entries. Watch suggestions and receive private Community Updates. Inspect suggestion history and moderate through new Create Suggestions / Manage Suggestions permissions. Existing server AutoMod inspects suggestion and comment text, including edits.

ACCESS AND DELIVERY
Permission, block, timeout and onboarding checks apply on the backend. Server layout templates preserve disabled suggestion permissions and keep profile/board content in the original server. Lost access closes open editors. Votes/watch state are independent of text-edit revisions; repeated creation/comment requests avoid duplicates. Windows release checks include a real 3.6-to-3.7 upgrade. Deploy main on Render and reopen clients for hosted features. Existing Android/iPhone 3.4 shells remain compatible.
