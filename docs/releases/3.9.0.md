Voxora 3.9.0 — Server management and bot templates

FOUR READY-TO-INSTALL BOTS
Install Economy, Music Queue, Games and Tasks from Server Settings → Bots & Apps.
Economy includes daily credits, transfers, a leaderboard and collectible badges.
Music Queue shares channel-specific HTTPS track links with DJ controls; it does not
stream audio into voice calls. Games adds dice, coin flips, choices and eight ball.
Tasks keeps per-user, per-channel task lists. Built-ins need no external process.

MORE MANAGEMENT CONTROL
Delegate bot management, invite moderation, message pinning, slowmode bypass,
channel archiving and music queue moderation through separate permissions. New
Bot Manager, DJ and Archivist role presets help with setup. Archive channels to
keep their history readable while preventing posting, uploads and new threads.

3.8 FEATURES NOW INCLUDED IN THE DESKTOP INSTALLER
Reusable role templates, expiring role assignments, delegated role assignment,
Bulletin channels and curated Links channels.

DATA AND UPDATES
Existing workspaces, accounts, bot installations and server connections are preserved.
The existing verified installer and hash-pinned automatic-update flow is unchanged.
Shared hosted connections need the matching backend deployment; local workspaces
run the backend bundled in this installer.
