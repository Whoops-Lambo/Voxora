Voxora 4.0.0 — Community management

Restore deleted channels, messages, threads and roles in Server Settings → Server Management. Add role-restricted emojis, boosted role icons, reaction roles, leveling, safe thread/forum moves and merges, webhooks and public live-chat widgets.

Voxora Max adds 1,000 commands per bot, 250 bot applications, ten shareable themes, six boosts, 80-member groups and 20 Workspace Scenes. Free and Plus now allow 200/400 commands per bot, 20/100 applications and 20/40-member groups. Boosts extend through level 5 with expanded media limits, recovery windows and storefront highlights.

Server stores support digital perks and physical products through Stripe Connect, paying the server owner with a configurable 5–10% Voxora platform fee (7.5% default, excluding shipping). Live purchases require platform configuration and seller verification.

Also includes Stage text chat, Rules & Onboarding and Showcase channel options, rich bot embeds/buttons, advanced search operators, personal channel lists, DM folders, account switching, audit export, game presence, a desktop game-chat shortcut and independent stream-audio controls.

Desktop automatic updates keep exact-installer Windows verification. Hosted users need the matching backend deployed. Stage uses peer-to-peer transport; expanded seat caps are not large-broadcast load-test claims. Music Queue remains a link queue. Game Chat supports windowed/borderless games. Android Play digital purchases stay disabled until the appropriate billing integration is configured; existing memberships remain usable.
