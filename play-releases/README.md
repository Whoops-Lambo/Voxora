# Google Play submission files

- [Signed Voxora 4.0.1 App Bundle](Voxora-4.0.1-play-release.aab): upload this `.aab` to Play Console.
- [Complete submission ZIP](Voxora-4.0.1-Google-Play-Submission.zip): includes the AAB, public upload certificate, release notes, policy copy, checksums and instructions.

On GitHub, open a file and choose **Download raw file**, or use its **Raw** link. The ZIP is for your convenience; Google Play accepts the extracted `.aab`.

Package `com.voxora.app`, version code **4000001**, target SDK **36**. Signed with the existing upload key. These files contain no private keystore or passwords.

Privacy Policy: https://voxora-public.onrender.com/privacy. In the app: **User Settings → Privacy Policy**. The Android app loads the hosted app interface, including its current policy page.

Developer verification, store listing, app-content declarations and any required testing are handled in your Play Console. This directory does not represent a Play submission or approval. Digital checkout in the Play build remains disabled until the appropriate billing integration is available.
