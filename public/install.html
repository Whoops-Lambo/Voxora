iPhone — install with background notifications

  1. Open Voxora in Safari.
  2. Tap Share, then Add to Home Screen.
  3. Keep Open as Web App enabled if shown, then tap Add.

Launch Voxora from your Home Screen and sign in. On iOS 16.4 or newer, open User Settings → Notifications → Enable Background Notifications, then allow the iPhone prompt. Use Send Test Notification to check delivery. No App Store submission, paid developer account or weekly renewal is needed.

iPhone — native sideload

Download iOS IPA

This native build must be signed for your device using an Apple ID through AltStore Classic or Sideloadly on your computer. A free Apple ID generally needs renewal every seven days. Downloading the IPA alone does not install it. An IPA signed with a free Apple ID cannot receive reliable push alerts while closed; use the Home Screen web app above for free background notifications. Native remote push requires Apple’s push-enabled developer provisioning.

Chat and calls require an internet connection. The installed Home Screen web app supports background DM and mention alerts after you enable them. In-app sounds and live updates also work while Voxora is running.

Keep the public account you already use. Your old local desktop workspace remains separate.
